# Odi Wa Turkana (Nighx)

Official media and entertainment application for **Odi Wa Turkana**, bringing authentic Turkana sound, culture, and community updates straight from Kakuma, Northern Kenya, to the world. 🇰🇪🎶

## 🚀 Features

*   **Social Feed**: Real-time updates and community engagement. Share updates, like posts, and comment on the latest news from Kakuma.
*   **Audio Tracks**: Stream official tracks and local sessions. Support for both remote streaming and local MP3 file playback.
*   **Video Library**: Watch live concert highlights, official music videos, and behind-the-scenes content from the Northern Kenya Tour.
*   **Local Storage Support**: Browse and play your own media files directly within the app.
*   **Persistent Data**: Local database integration using SQLite to keep your feed and interactions saved.

## 🛠️ Built With

*   **Flutter**: For the cross-platform mobile experience.

*   **File Picker**: To access local device media.

## 📦 Getting Started

### Prerequisites
*   Flutter SDK: `^3.12.1`
*   Android Studio / VS Code
*   Active Internet Connection (for streaming)

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/ChrisEjore/nighx.git
    ```
2.  Navigate to the project folder:
    ```bash
    cd nighx
    ```
3.  Install dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the app:
    ```bash
    flutter run
    ```
